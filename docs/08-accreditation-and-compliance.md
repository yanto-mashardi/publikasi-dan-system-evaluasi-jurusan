# Accreditation and Compliance

## Principle

Akreditasi tidak mempunyai database fakta sendiri.

Framework akreditasi berisi:

```text
framework
criterion
indicator
requirement
calculation_rule
evidence_requirement
mapping
```

## Mapping

```text
Accreditation Indicator
       ↓
Domain Metric / Document
       ↓
Source Record
       ↓
Evidence
       ↓
Assessment
```

## Official Status vs Internal Assessment

### Official
Dapat dipublikasikan sebagai:

- status akreditasi;
- lembaga;
- SK;
- tanggal;
- masa berlaku.

### Internal Readiness
Harus diberi label:

> Evaluasi Kesiapan Internal

Tidak boleh disajikan seolah-olah merupakan skor resmi lembaga akreditasi.

## Framework Adaptability

Sistem harus dapat menambah:

- BAN-PT;
- LAM tertentu;
- audit internal;
- standar institusi;
- regulasi baru;

tanpa mengganti master data.
